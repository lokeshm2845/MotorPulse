# MotorPulse — Round 3 demo video script (about 4 minutes)

Record the phone screen (Android: built-in screen recorder) plus a second camera on the pump if you can.
Speak slowly; show the screen long enough to read. Keep every simulated sample visibly labelled "SIMULATED".

| Time | Show | Say |
|---|---|---|
| 0:00–0:20 | Title slide, then a running farm pump | "Pumps rarely fail suddenly — they sound different for weeks first. MotorPulse lets a farmer hear that change with just a phone." |
| 0:20–0:40 | Open the app on the phone; switch EN → हि → म | "It's an installable app that works fully offline, in English, Hindi and Marathi." |
| 0:40–1:20 | **Add machine** → name "Well pump" → **Record healthy sound** ×3 on a real motor/fan (hold phone ~10 cm, same spot) | "First we teach it this pump's healthy sound — three 10-second recordings. That becomes the pump's own sound fingerprint, stored on the phone." |
| 1:20–1:40 | Show the quality gate: talk while recording → "Sound was not steady… record again" | "Bad recordings are rejected with clear guidance, so the farmer never gets a wrong answer from a bad clip." |
| 1:40–2:10 | **Check now** on the healthy motor → Green, health ~90, voice speaks | "A normal check: green, healthy, spoken aloud. Analysed on this phone in milliseconds — no internet." |
| 2:10–2:40 | Real fault: tape a small coin/weight to a fan blade or loosen the motor mount → **Check now** → Yellow/Red | "Now we create a real fault — an imbalance. The sound changed, and MotorPulse catches it immediately." |
| 2:40–3:10 | Open the **Demo pump (SIMULATED)** → run *Bearing wear (severe)* and *Cavitation* | "With simulated recordings we can show every fault type: bearing wear, cavitation, imbalance, electrical — each with a likely cause and what to do." |
| 3:10–3:30 | Result screen: cause, confidence, advice, cost; tap **Share with mechanic** (WhatsApp) | "The farmer gets a clear next step and can send the report to a mechanic in one tap." |
| 3:30–3:50 | History chart + "Health is falling" trend warning | "Every check builds a health timeline; a falling trend triggers an early warning." |
| 3:50–4:10 | Laptop: fleet dashboard with synced machines | "When the phone is online, results — never audio — sync to a dashboard for FPOs and panchayats." |
| 4:10–4:30 | Slide: real-data result (DCASE AUC) + next steps | "On real public pump recordings, with just three enrolment clips per pump, MotorPulse reaches the accuracy shown here. Next: a field pilot with an FPO." |

### Tips
* A table fan or a small motor is a perfect safe stand-in for a pump. Imbalance: stick a coin to one blade. Looseness: loosen a mounting screw. Never touch moving parts.
* Turn voice on in Settings so the result is spoken during the video.
* Phone access to the app needs HTTPS (see README: `ngrok http 8000` or GitHub Pages).
